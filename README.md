# Master-Thesis-Remote-Sensing
Master's thesis Topics: analysis of long-range transboundary pollution during the Northeast Monsoon in Taiwan using satellite-derived Aerosol Optical Depth (AOD) and aerosol types.

Description: This repository contains MATLAB programs developed for my master's thesis. The research integrate satellite remote sensing products, atmospheric data, and air mass trajectories to investigate aerosol characteristics, spatial distributions and transport patterns. It also applies aerosol optical depth (AOD)-based relationships for PM2.5 concentration estimation and evaluates satellite-derived PM2.5 products through comparisons with ground-based air quality observations.
